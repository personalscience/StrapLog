# Testing

| Layer | Framework | Runs on | Command |
|---|---|---|---|
| `HRVKit` | Swift Testing | macOS | `(cd Packages/HRVKit && swift test)` |
| `StrapLogCore` | Swift Testing, in-memory GRDB | macOS | `(cd Packages/StrapLogCore && swift test)` |
| App unit (`StrapLogTests`) | Swift Testing | iOS Simulator | `xcodebuild test -scheme StrapLog -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath build/dd` |
| App UI (`StrapLogUITests`) | XCTest UI | iOS Simulator | same scheme |

- Logic belongs in the packages so it is covered by the fast macOS runs. The Polar adapter is deliberately thin and is exercised through `HeartSource` fakes.
- Fixtures: `Tests/fixtures/<rec>.json`, generated by `tools/gen_fixtures.py`, which imports `analyze_h10.py` itself (with `chart_style` stubbed), so expected metrics are the skill's own numbers, never re-derived by hand. `t_rel` is rounded to 1 ms *before* the reference is computed, so the fixture is self-consistent.

  |---|---|---|---|
  | `resting` | `~/Downloads/hrv260420/DB.sqlite` pk 4 (DREAMPHONES, 20 min) | 961 | 19 |
  | `strength` | `~/Downloads/strength260720/DB.sqlite` pk 16 (69 min) | 6,177 | 68 |
  | `overnight` | `~/Downloads/strength260720/DB.sqlite` pk 15 (SLEEP260719, 9 h) | 34,034 | 539 |

  Regenerate: `tools/gen_fixtures.py --db <DB.sqlite> --pk <n> --name <fixture>`. If `analyze_h10.py` constants change, regenerate; `FixtureParityTests` checks the recorded constants against `HRVDefaults`.
- HRVKit parity (`FixtureParityTests`): identical removed-beat indices and per-window counts; RMSSD/SDNN ±0.1 ms; α1 ±0.02. SDNN is ddof = 1 (Python's script doesn't compute SDNN; the fixture tool does, with `np.std(ddof=1)`).
- DFA at scales 4–16 reads white noise as α1 ≈ 0.59, not the theoretical 0.5 (numpy reference: 0.587 ± 0.013 over 30 seeds); random walk reads 1.50. Synthetic tests assert the estimator's values.
- Data checks on exported snapshots use plain `sqlite3`: monotonic `received_at_ms`, Σrr vs elapsed, balanced connect/disconnect, `n_rr == count(beat)`.
